# Preparing an application

Give an agent access to your own academic archive and paste this brief with the application requirements.

```text
Read README.md, profile.yml, publications.yml, and the relevant projects/ records.
Prepare [CV, personal statement, or research proposal] for [program or position].
Use the attached requirements to select relevant experience and decide the structure.
Distinguish my contribution, the evidence, the scope of each result, and proposed work.
Flag facts that need confirmation and save a local draft for review.
For a CV PDF, run build_profile.py, then use the generated Master CV YAML as the
basis for a separate application version. Render it with RenderCV.
```
